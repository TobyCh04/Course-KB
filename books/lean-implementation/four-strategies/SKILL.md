# Four Strategies to Becoming Lean (精益四策略)

## R — Reading (原文引用)

> "The overall approach to make a value stream lean consists of four key strategies: 1. Synchronize supply to the customer, externally. 2. Synchronize production, internally. 3. Create flow. 4. Establish pull-demand systems." — Ch 7, p.111

## I — Interpretation (方法论骨架)

Four sequential strategies to transform a manufacturing process from chaotic to Lean:

1. **External Synchronization (外部同步)**: Match production rate to customer demand using takt time. Use safety stock (supply variation) and buffer stock (demand variation) to handle normal variation. Level the model mix when multiple products share a line.

2. **Internal Synchronization (内部同步)**: Balance the production line so all workstations operate at takt time. Use time studies and balancing analysis to identify and resolve imbalances.

3. **Create Flow (创建流)**: Reduce batch sizes, implement one-piece flow, organize into cells. Minimize WIP between stations.

4. **Establish Pull (建立拉动)**: Implement kanban systems to authorize production only when downstream demand exists. Use supermarkets for shared components.

**Five diagnostic tools**: Takt calculation, time study, balancing analysis, spaghetti diagram, value stream mapping.

**Seven wastes to eliminate**: Transportation, Waiting, Overproduction, Defects, Inventory, Movement, Excess Processing (TWO DIME).

## A1 — Past Application (书中案例)

The Alpha Line (Ch 14) applied all four strategies sequentially: synchronized externally with takt-based scheduling, balanced internal operations, created flow through cellular manufacturing, and established pull with kanban. Result: 63% production rate improvement with no capital expenditure.

## E — Execution (执行步骤)

1. **Map the current state**: Create a value stream map showing material and information flow
2. **Calculate takt time**: Available production time / customer demand rate
3. **Do time studies**: Measure cycle time at each workstation
4. **Create balancing analysis**: Compare cycle times to takt time; identify imbalances
5. **Draw spaghetti diagram**: Map physical movement of material and people
6. **Design future state**: Apply the four strategies in order
7. **Create implementation plan**: List kaizen activities on a Gantt chart
8. **Execute and verify**: Implement changes, measure results, repeat

## B — Boundary (边界条件)

- **NOT for**: Non-manufacturing processes without significant adaptation
- **NOT for**: Processes where the constraint is outside manufacturing (sales, engineering)
- **Requires**: Stable processes (standard work must exist before flow)
- **Requires**: Multiskilled workers (cells need flexible staffing)
- **Limitation**: This is a manufacturing-focused framework; service industries need different approaches
