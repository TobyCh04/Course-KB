# Eight-Step Lean Project Prescription (精益项目处方)

## R — Reading

> "The implementation of our Lean initiative is outlined here for ease of understanding. It will be managed and executed like any large project. The action items for this project will be compiled from two sources. The first set of data is gathered from the 'systemwide evaluations,' while the second portion will be from the 'specific value stream evaluation.'" — Ch 8, p.135

## I — Interpretation

An eight-step methodology for Lean implementation, divided into two phases:

**Phase 1: Systemwide Evaluations (Steps 1-3)**
1. Assess three fundamental cultural change issues (leadership, motivation, problem solving)
2. Complete systemwide evaluation (management commitment test, 10 failure reasons, 5 precursors, process maturity)
3. Perform educational evaluation of the workforce

**Phase 2: Value Stream Evaluations (Steps 4-8)**
4. Document current condition (present state value stream map)
5. Redesign to reduce waste (future state VSM, spaghetti diagram, kaizen activities)
6. Evaluate and set goals (critical process indicators, specific line goals)
7. Implement kaizen activities (finished goods controls first, then jidoka, then all others)
8. Evaluate new present state, stress the system, return to step 4

**Key decision**: Implement one value stream at a time, not "clean sweep."

## A1 — Past Application

Three case studies in Ch 16 applied this prescription to different facilities. Results varied based on management commitment and precursor readiness — companies that passed all five commitment tests and addressed all five precursors achieved the best results.

## E — Execution

1. **Run management commitment test** (5 yes/no questions from Ch 19)
2. **Assess 5 precursors** (management commitment, stable processes, reliable suppliers, trained workforce, proper MRP)
3. **If precursors pass**: Select one value stream to start
4. **Create present state VSM** (current material and information flow)
5. **Design future state VSM** (apply four strategies)
6. **Set goals** (protect customer first, then improve)
7. **Create Gantt chart** with all kaizen activities, milestones, responsibilities
8. **Implement in order**: finished goods controls → jidoka → all other kaizen
9. **After implementation**: evaluate new state, stress test, repeat from step 4

## B — Boundary

- **NOT for**: Incremental improvements to an already-Lean system
- **NOT for**: Companies that can't pass the management commitment test (fix leadership first)
- **Requires**: Dedicated resources and management support
- **Warning**: If precursors aren't addressed, the initiative will fail (see counter-examples)
